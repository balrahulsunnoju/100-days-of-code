If missing, STOP and instruct user to run `/tdgs-aidlc-setup-testdata` first. (Dashboard-refresh rule — see `/tdgs-aidlc-setup-api-tests` line 1677.)

### Script Chain Architecture

**`test:e2e:mock` / `test:e2e:real` MANDATORY (R10-B11).** `cross-env` makes the `TEST_MODE=` variable assignment portable to Windows. The `sh -c` wrapper for exit-code-preserving chaining requires a POSIX shell — available on macOS/Linux natively and on Windows via Git Bash (ships with Git for Windows, which all developers have installed). If the team has Windows-only environments without Git Bash, replace `sh -c` with a Node-based wrapper script (`scripts/run-with-reports.js`) that captures exit code programmatically. Chain with exit-code-preserving `sh -c` wrapper (NOT plain `;` which masks exit code, and NOT `&&` which skips reports on failure) so reports regenerate on failure AND CI still sees the failure exit code. Real mode honors `TEST_BASE_URL` (set by `/tdgs-aidlc-run-tests`) and otherwise hits the UI's local backend via its discovered proxy/route config — do NOT hard-code prefixes.

**NEVER pass `--reporter=…` on the Playwright CLI (HARD RULE).** CLI `--reporter=` REPLACES the entire `reporter[]` array (no merge), dropping `html` + `json` reporters → no `results.json` → `testSummary={total:0,…}` → dashboard tiles zero, ledger `runs[]` skipped, "No runs yet" forever. All `scripts.test:e2e*`, `/tdgs-aidlc-run-tests` invocations, and README examples MUST run `npx playwright test [filters]` with NO `--reporter=` flag. For richer console: `DEBUG=pw:api npx playwright test`.
